# SQLite amalgamation

This directory contains `sqlite3.c` and `sqlite3.h` from the official SQLite
3.53.4 amalgamation (`sqlite-amalgamation-3530400.zip`). SQLite is in the public
domain. It is embedded so Android library consumers get consistent, supported
MBTiles access without depending on Android's private native SQLite library.

Source: https://www.sqlite.org/2026/sqlite-amalgamation-3530400.zip
